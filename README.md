# dx

This tool is a random number generator for simulating dice (dx) rolls. 
Handy if you went to a D&amp;D session but left your favorite dice at home.
You have different way for telling how many dice and what kind of dice you would like to roll:
you can specify it as a string (e.g. `3d6+2` means rolling three six-sided dice and adding two to the result, 
simple <a href="https://en.wikipedia.org/wiki/Dice_notation">dice notations</a> are supported only),
but you can also set a minimum and a maximum value, or just click one of the roll buttons.

The file www/dx.js is the library where you can create classes of dicerolls.

The file index.html serves as a demo for this.

See <https://dx.berta.hu> to see it in action.
